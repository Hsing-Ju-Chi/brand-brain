## 三、做簡報時的挑法

| 大腦寫的圖片風格 | 優先用 | 備援 | 放哪裡 |
|---|---|---|---|
| 手繪感人物、親切 | Open Doodles、Open Peeps | Storyset（記得標出處） | 封面角落、三欄重點旁 |
| 線條人物、線稿 | Notion Avatar Maker、Pixel True 線稿 | Humaaans | 團隊介紹頁、流程角色；線色改主色 |
| 手繪貼紙、塗鴉、箭頭 | Doodle Icons | dddoodle（要署名） | 圈重點、指數據；一頁最多 2 到 3 個 |
| 扁平場景、乾淨 | Lukasz Adam、Humaaans | unDraw（題材最廣，官網改成品牌色） | 左文右圖的右半 |
| 水彩、印章 | FreeSVG | Pixabay 向量 | 封面角落暈染、章節頁背景，透明度 20 到 40%，避開文字 |
| 等距 | Pixabay 向量、FreeSVG | 只能連結的 ManyPixels | 一頁一張當主圖，不要縮成 icon |
| 3D 物件 | 3dicons | 無 | 取代 bullet icon；整份同一角度 |
| 紙紋、拼貼 | Texturelabs 紙紋、克里夫蘭古畫去背 | Pexels 紙紋照片 | 紙紋鋪底（塗鴉、紙本兩款）；古畫當封面主視覺 |
| 實景照片 | 先放主色色塊佔位＋給搜尋詞 | Unsplash／Pexels 連結 | 左文右圖、封面照片區 |
| icon | Lucide（預設）或 Tabler | Phosphor | 三欄重點、步驟 |

規則：
- **一份簡報一套 icon**，不混庫；線條粗細統一（stroke 1.5 或 2），顏色用主色。
- 插圖只挑同一庫、同一風格，不要一頁手繪一頁扁平。
- 第二區的庫，你只給「去哪裡、搜什麼、改成什麼色」，讓使用者自己下載後放進 `assets/`，再由你嵌入。不准自動抓。
- 第一區的 icon 可以由你直接抓 SVG 內嵌（jsdelivr 範例：`https://cdn.jsdelivr.net/npm/lucide-static/icons/coffee.svg`，回傳含授權註解）。
