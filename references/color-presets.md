# 8 款代表範本（配色 × 字型 × 底稿 × 場景）

使用者沒有色系、只說得出「感覺」或「要做什麼簡報」時，從這8 款挑。每款＝一套配色＋字型組合＋版型預設＋一種底稿風格，**挑一款就等於三題一次答完**，之後只需微調。每款都有九頁範例（`examples/{slug}.html`，第 1 頁是 Design System）和填好的範例大腦（`templates/examples/brand-brain-{slug}.md`）。

所有色碼的文字／背景對比皆 ≥ 12、主色與強調色對背景 ≥ 4.0（WCAG 公式實算）。字型全部在 Google Fonts 上（以 Google Fonts API 逐一確認）。

## 底稿風格庫（整份簡報每頁共用的一層，決定氣質）

底稿＝疊在背景色上、文字底下的那一層，加上封面與章節頁的裝飾構圖。全部純 CSS 或內嵌 SVG，不用外部素材檔，ChatGPT 免安裝版也做得出來。名字跟《視覺效果溝通詞典》對齊（玻璃擬態＝詞典 01、顆粒＝16）。

規則：
- 一份簡報一種底稿，每頁共用；換底稿一句話「底稿換手繪」。
- **可讀性**：文字所在區域的底稿元素透明度不超過 .3（柔光、顆粒、網格、塗鴉都算；裝飾色塊要避開文字區）；深底淺字或淺底深字的對比不因底稿變差。
- 底稿輔助色只准出現在底稿色塊，不進文字、卡片文字、icon。
- 漸層只准出現在底稿的柔光層，不准用在文字、卡片、色塊。
- 使用者已有色系或從簡報抽色時，底稿依「版型怎麼配」挑到的範本帶預設；使用者說「底稿要 X」就照他的。
- PPTX：底稿層與封面構圖燒成圖鋪滿背景，文字、卡片、icon 原生可編輯（`references/pptx-bake.md`）；紙紋塗鴉的手繪框在圖層裡。

## 所有範本共用的固定值（不問使用者）

- 畫布 16:9，1280×720；頁邊依範本
- 字級階層：封面主標 72 ／ 頁面標題 40 ／ 內文 22 ／ 註解 14
- 用色比例 60-30-10：背景 60%、主色 30%、強調 10%（強調色只放關鍵數字或一個重點）
- 深底淺字或淺底深字，不做中間灰
- **垂直分布**：內容不到字量上限一半時，重點區垂直置中或字級放大；每頁至少兩個視覺區塊（標題＋內容），不留空半頁
- 標題區預設：內容頁左上；封面依範本的封面構圖
- footer 與頁碼預設：右下頁碼 14px 主色；右上品牌字樣
- 章節頁預設：背景換主色、大編號淡化（.35）、章節名反白置左（玻璃、紙本、極簡三款不換底色；粉彩換強調綠；螢光換桃紅）
- **Design System 頁**：每份簡報第 1 頁，六格：色票（含底稿輔助色）、字型、底稿風格、元件（icon 與卡片規格）、場景、頁型。做簡報時先出這一頁，再接內容

## 版型怎麼配（所有路徑共用）

| 用色從哪來 | 版型與底稿用哪款 |
|---|---|
| 使用者挑了範本 | 就是那款 |
| 已有色系、從簡報或 logo 抽色、參考品牌抽色 | 先看底色，再看**主色**的色相（強調色不算）：深底＋高飽和螢光 → 螢光撞色（撞色分割）；深底 → 玻璃科技；淺底、主色藍或灰、正式 → 簡潔提案；淺底、主色藍或灰、要數據 → 便當格；淺底、主色橘紅黃或手寫感 → 塗鴉手繪；淺底、主色綠或棕 → 紙本雜誌；淺底、多色粉彩 → 粉彩玩趣；黑白灰為主 → 靜物極簡 |

只借版型與底稿，顏色與字型照使用者的。

## 從參考品牌抽色（使用者說「像法拉利 F1」「像 Muji」「像 Apple 發表會」）

1. 先講你對這個參考的視覺印象：兩到三個關鍵色＋一句它為什麼有那個感覺（例：法拉利＝賽車紅＋碳纖黑，硬、快）。
2. 抽成四個角色：主色、背景、文字、強調。色碼標「參考值，非對方官方規範」。
3. 明講一句：**這是靈感不是複製，不會用對方的 logo、字型、圖形。**
4. 檢查與使用者品牌的落差（例：賽車紅配精品咖啡偏硬），講出來並附一個建議（照走／壓暗／換範本），跟色碼放同一則訊息；使用者不反對就照建議走，不另開一題。
5. 版型與底稿：照上面「版型怎麼配」挑。法拉利是深底 → 玻璃科技（要更潮就螢光撞色）。

## 使用者已有色系時

- 有主色＋輔色 → 主色照給；輔色當強調；背景與文字由你補（淺底就 `#F7F7F5` 系＋近黑文字，深底反過來），附色碼請確認。
- 有完整品牌規範 → 全部照規範，不加不減。
- 使用者給 logo 或截圖 → 從裡面抽色，附色碼請確認。
