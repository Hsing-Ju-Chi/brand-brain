# 品牌大腦：夜行（範本「螢光撞色」，換成你的品牌）

> 最後更新：2026-09-07
> 用法：做簡報前，把這整份檔案先貼給 AI（或讓 skill 自動讀），再給簡報內容。
> 這是 brand-brain 8 款代表範本之一（templates/examples/）：品牌「夜行」是虛構的，把第 0 節換成你的，其餘可以直接用。配套九頁範例簡報在 examples/neon.html（PPTX 版 examples/neon.pptx），第 1 頁就是這份大腦的 Design System。

## 0. 定位

- 品牌是做什麼的：夜行（範例，換成你的）
- 簡報通常做給誰看：（換成你的）
- 整體感覺（範本名或三個形容詞）：螢光撞色
- 適合場景：潮流品牌、音樂、活動、新品上市

## 1. 用色系統（顏色只准從這裡拿）

- 來源：範本「螢光撞色」
- 主色：#C6FF00（用在：標題、色塊、icon）
- 背景色：#0F0A1E
- 文字色：#F2F2F2
- 強調色：#FF3D8A（只放關鍵數字或一個重點）
- 比例：背景 60%、主色 30%、強調 10%
- 底稿輔助色：#2D6BFF（只准用在底稿色塊，不進文字與卡片文字）
- 要加新色，先問我。

## 2. 字型

- 標題字型：Noto Sans TC，載入方式：只用 Google Fonts Noto+Sans+TC:wght@900
- 內文字型：Noto Sans TC，載入方式：只用 Google Fonts Noto+Sans+TC:wght@300
- fallback：PingFang TC, Microsoft JhengHei, sans-serif
- 字級：封面主標 72 ／ 頁面標題 40 ／ 內文 22 ／ 註解 14（全簡報一套）

## 3. 版型預設（跟著範本走，要改哪條直接說）

- 留白：適中（頁邊 88px）
- 對齊：置左
- 圓角：無
- 陰影：無
- 行距：1.6
- 每頁字量上限：45 字，超過就拆頁，不縮字
- 垂直分布：內容不到上限一半時，重點區垂直置中或字級放大，不留空半頁
- **底稿風格：撞色分割**（右側桃紅實色直帶（封面 38%，帶上整條直排英文名；內頁 56px 貼右緣）；沒有漸層；卡片只用桃紅上緣線；標題第二行描邊；章節頁桃紅底；整份每頁共用，換底稿說一句「底稿換 X」）
- 標題區：內容頁左上；封面左下主標
- footer 與頁碼：右下頁碼，14px 主色；右上品牌字樣
- 章節頁：桃紅底、大編號淡化
- 頁型庫（做簡報時照這八種排，內容多就重複內容頁型）：Design System → 封面 → 章節頁 → 三欄重點 → 左文右圖 → 一頁一數字 → 步驟流程（順序才用編號） → 封底（一句話＋聯絡方式）
- PPTX：底稿層燒成圖鋪滿背景，文字、卡片框、icon 原生可編輯（references/pptx-bake.md）

## 4. 資產風格

- icon：Lucide，線條粗細 2，用主色
- 插圖：扁平線條（unDraw、Lukasz Adam）改成螢光色
- 照片：夜景、霓虹、高對比、人物剪影；沒照片時用主色色塊佔位並標搜尋詞

## 5. 禁區

- 不要出現：emoji 當圖示、超過兩種字型、色票以外的顏色（底稿輔助色只准在底稿）；漸層只准出現在底稿的柔光層，不准用在文字與卡片
